# Conversion

**Conversion** is a completely offline, secure file converter desktop application featuring a nostalgic, retro Windows XP-inspired user interface. By keeping all processing local to your machine, it ensures your sensitive documents never leave your computer.

## ✨ Features

- **100% Offline**: No internet connection required. All conversions happen securely on your local CPU.
- **Retro Aesthetic**: Designed from the ground up to mimic the classic Windows XP look and feel, including period-accurate colors, progress bars, and borders.
- **PDF to DOCX**: Accurately convert your PDFs into editable Microsoft Word documents.
- **PDF to Images**: Extract pages from your PDF into a `.zip` file of images (PNG, JPEG, or WEBP).
- **Native Experience**: Packaged as a standalone Windows `.msi` and `.exe` installer.
